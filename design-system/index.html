Themes

Light and dark are driven by a single data-feed-theme attribute on <html>.

Use the floating Toggle Dark Mode control to flip data-feed-theme on <html>. Auth and parent pages apply the same attribute inside .auth-path-shell; this docs page mirrors those tokens so you can preview both themes here.
